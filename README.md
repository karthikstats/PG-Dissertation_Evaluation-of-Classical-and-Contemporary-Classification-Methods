# Categorical Response Regression: Traditional and Machine Learning Methods

## Project Overview
This project compares traditional statistical regression methods and modern machine learning algorithms for categorical response data.

## Objectives
- Study regression methods for binary, multinomial, and ordinal response variables.
- Implement classification models using R.
- Compare model performance using confusion matrices, accuracy, and other suitable evaluation metrics.
- Identify the strengths and limitations of the methods.

## Methods
### Binary Response
- Binary Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- XGBoost

### Multinomial Response
- Multinomial Logistic Regression
- Quadratic Discriminant Analysis (QDA)
- Random Forest
- SVM
- XGBoost

### Ordinal Response
- Ordinal Logistic Regression
- Ordinal Forest
- SVM
- XGBoost

## Tools and Technologies
- R
- RStudio
- Statistical modelling and machine learning packages
- Data visualization and model evaluation
